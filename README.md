# bm-background-geolocation

A Capacitor plugin for background geolocation and real-time GPS tracking on Android and iOS.

## Install

To use npm

```bash
npm install bm-background-geolocation
````

To use yarn

```bash
yarn add bm-background-geolocation
```

Sync native files

```bash
npx cap sync
```
